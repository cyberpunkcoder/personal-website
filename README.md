# chandlerjohnson.com

Single-page personal site. Static, no build step. Served from GitHub Pages.

- `index.html` — everything (markup + CSS inline)
- `assets/hero.mp4` — 7.7 s loop, 1080p, ~1.6 MB (Humvee wide → headset close-up)
- `assets/poster.jpg` — first-paint fallback + OG image
- `CNAME` — custom domain for Pages

Preview locally: `uv run --with rangehttpserver python -m RangeHTTPServer 8090`
